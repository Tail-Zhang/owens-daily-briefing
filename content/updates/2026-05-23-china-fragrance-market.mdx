# 2025-2026 中国香水市场核心数据

## 关键数字

| 指标 | 数据 |
|---|---|
| 2025 年零售额 | **300 亿元**（Euromonitor） |
| 近五年复合增速 | **18.9%**，全球增速的 3 倍 |
| 市场渗透率 | **仅 5%**（欧美 30-40%） |
| 本土品牌份额 | **32.4%**（2020 年仅 18.7%） |
| 高端香水贡献率 | 从 35% 升至 **42%** |

## 三大趋势

**1. 本土品牌加速崛起**

观夏、闻献、melt season 等本土品牌正在用「东方叙事」重新定义中国香水。不再依赖桂花、茉莉等单一中式香材标签，而是构建完整的品牌世界观——从产品命名到空间设计到内容营销，形成「东方生活方式」的统一表达。

**2. 内容电商重塑决策链路**

抖音香水类目 GMV 同比增长超过 100%。短视频种草 + 场景化内容 + 直播转化，正在改变传统香水「先闻后买」的决策模式。品牌通过「气味可视化」（氛围感视频、场景叙事）弥补线上无法试香的短板。

**3. 下沉市场爆发**

三线及以下城市香水消费增速（+35%）远超一线城市（+12%）。小镇青年成为增量主力——他们通过社交媒体接触到 niche 香氛文化，但线下渠道稀缺，因此高度依赖线上购买。

## 策略启示

渗透率 5% 意味着 95% 的中国消费者还没有固定的香水使用习惯。这不是一个存量竞争市场，而是一个**用户教育驱动的增量市场**。品牌的竞争不是从对手那里抢份额，而是让更多中国人「开始用香水」。
